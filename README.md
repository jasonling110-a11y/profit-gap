# 利润断层工作台

每个交易日自动扫描 **A 股「利润断层」** 个股：业绩预告 / 业绩快报 / 正式财报中出现**净利润增速断层式跳升**（利润断层），并在公告后出现**跳空高开缺口**（价格断层）的标的。两个断层同时出现 = **核心池·双断层**。

---

## 一、快速开始

```bash
cd /Users/jason/Desktop/利润断层

# 每天扫一次（默认近 7 天公告窗口）
./run_daily.sh

# 放大窗口看整个财报季（例：半年报季）
DAYS=60 ./run_daily.sh --period 20260630

# 放宽增速门槛
./run_daily.sh --min-yoy 30 --min-accel 10
```

执行后产物：

| 文件 | 说明 |
|---|---|
| `利润断层工作台.html` | 主看板（单文件、双击即开、无外部依赖） |
| `data/scan_latest.json` | 最新一次扫描的结构化结果 |
| `data/scan_YYYYMMDD.csv` | 当日清单（Excel 可直接打开） |
| `data/历史信号.csv` | 累积信号库（去重，按 代码+公告日+分层） |
| `data/简报_YYYYMMDD.md` | Markdown 简报，便于快速浏览 |

## 二、判定口径（本工具的定义）

**利润断层（基本面）**
1. 本期净利润增速 ≥ `--min-yoy`（默认 50%）；优先用**单季同比**口径，数据不足退回累计同比（表内「口径」列标注）。
2. 增速加速度 = 本期增速 − 上期增速 ≥ `--min-accel`（默认 20pct）。
3. 单季净利由「本季累计 − 上季累计」差分得到，单季同比 = 单季净利 ÷ 去年同期单季净利 − 1。

**价格断层（市场确认）**
- 公告日或其次一交易日，开盘价相对前收盘涨幅 ≥ `--min-gap`（默认 2%）＝ 跳空高开。
- 「缺口未回补」= 跳空日之后所有交易日的最高价都未跌破跳空日的前一日最高价。
- **缺口回补即剔除**：一旦已形成的跳空缺口被回补，说明价格断层失效，该股**直接从清单删除**（KPI 与页头会显示本轮剔除数量，页面底部「已剔除：缺口回补个股」可展开回看，含回补日与回补耗时）。注意：从未形成有效跳空（<2%）的个股属于「观察池」，不在此列，不会被删除。

**分层**

| 分层 | 含义 |
|---|---|
| 核心池·双断层 | 利润断层 + 跳空高开，且非低基数 |
| 观察池·仅利润断层 | 基本面断层已现，等价格确认 |
| 观察池·低基数断层 | 上年同期单季净利 < 1000 万 / 增速 > 3000% / 上年亏损，增速失真 |
| 跟踪·仅价格缺口 | 有跳空但未达增速门槛 |

**评分（0-100）**：增速强度 30（增速按 300% 封顶）＋ 增速加速度 20 ＋ 跳空幅度 20 ＋ 缺口未回补 15 ＋ 成交额流动性 10 ＋ 财报质量 5 − 低基数 12 − 流通市值 < 30 亿 5。

**风险标记**：预增原因含「投资收益 / 资产处置 / 政府补助 / 债务重组 / 汇兑」等 → 非经常损益嫌疑；另标扭亏、ST、增速极端、流通市值偏小。

## 三、看板功能

1. **断层强度分布**：散点图（横轴增速 / 纵轴跳空 / 气泡成交额），增速轴上限 500%，超出者靠右显示（虚线圈）。
2. **板块分布 + 板块全景**：按东财「所处行业」聚合断层个股，展示各行业的断层数量、核心池数量、核心占比、缺口未回补数、平均增速、平均跳空、平均评分与代表个股；点击任一板块（分布条或表格行）即筛选下方清单。
3. **点击查看 K 线图**：点击清单任意行、「K线」按钮、明细卡片或已剔除行，弹出该股 K 线（红涨绿跌蜡烛 + 成交量 + MA5/10/20 + 公告日竖线 + 跳空缺口区间阴影）；鼠标悬停显示单日 OHLC 与成交量；按 `Esc` 或点击遮罩关闭；支持键盘操作（Tab 聚焦、回车打开、焦点困在弹窗内）。
4. **深链**：`利润断层工作台.html#k=300378` 可直接打开指定个股的 K 线图。
5. **筛选与排序**：搜索、行业、上市板块、分层四个筛选器 + 重置按钮；清单 19 列全部可点击表头排序。

## 四、数据源

| 数据 | 来源 |
|---|---|
| 业绩预告 / 快报 / 正式财报 | 东方财富数据中心（akshare：`stock_yjyg_em` / `stock_yjkb_em` / `stock_yjbb_em`） |
| 日线行情（缺口、成交额、流通市值） | 新浪财经（akshare：`stock_zh_a_daily`），腾讯财经兜底 |
| 交易日历 | 新浪（`tool_trade_date_hist_sina`） |

均为公开数据，本地缓存于 `data/cache/`（财报缓存 12 小时，行情缓存 7 小时）。

> ⚠️ 行情接口依赖 mini-racer(V8)，**不可用多线程**；引擎已改为多进程并行（`--workers`，默认 5）。

## 五、常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--days` | 7 | 公告日期回看自然日 |
| `--period` | 自动 | 指定报告期 `YYYYMMDD`，自动模式取最近两个报告期 |
| `--min-yoy` | 50 | 增速门槛（%） |
| `--min-accel` | 20 | 加速度门槛（pct） |
| `--min-gap` | 2 | 跳空门槛（%） |
| `--min-np` | 0 | 单季净利下限（元） |
| `--min-mcap` | 0 | 流通市值下限（元） |
| `--boards` | 主板,创业板,科创板 | 板块过滤 |
| `--workers` | 5 | 行情抓取进程数 |
| `--exclude-st` | 开 | 剔除 ST / 退市风险股 |
| `--hist-days` | 80 | K 线缓存交易日数（决定弹窗可见的历史长度与 HTML 体积） |
| `--keep-filled` | 关 | 保留缺口已回补的个股（默认剔除） |

## 七、已知限制

1. **公告时点差异**：部分公告在盘后发布，跳空出现在次日；引擎对「公告日 / 次日」取跳空更明显的一天，但若公告发布晚于行情收录，需要次日再跑一次才准。
2. **预告口径粗**：业绩预告只有累计区间增速，无单季值；「增速加速度」用上期累计增速近似，已在表内标注口径。
3. **单季差分的适用性**：正式财报的累计值差分对数据缺失（如财报更正、会计政策变更）敏感，个别公司单季值可能异常，需人工复核。
4. **低基数是最大噪音源**：已标记并降权，但无法完全自动排除一次性损益，实盘务必看公告原文。
5. **不含北交所**（默认过滤）、不含港股与美股。

> 本工具仅供研究参考，不构成个人投资建议。
